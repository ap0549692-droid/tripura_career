# Tripura Career - Jobs & Scholarships Portal

A complete Laravel-based job portal for Tripura students to find latest Govt Jobs, Private Jobs, Scholarships, Admit Cards & Results.

### 🚀 Live Demo
https://tripura-career.vercel.app

### ✨ Features
- Auto Job Fetch without Cron (Custom Scheduler)
- Admin Panel for Jobs/Scholarships/Admit Cards
- SEO Optimized with dynamic meta tags
- Scholarship & Admit Card Management
- Responsive Design for Mobile Users

### 🛠️ Tech Stack
- Laravel 11, PHP 8.2
- MySQL, Eloquent ORM
- Blade, Tailwind CSS, Vite
- Docker Ready

### ⚙️ Installation
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
